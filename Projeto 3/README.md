# Projeto 3 — Central de Inteligência de Gotham

Dashboard web do Bat-Sinal. O backend Node.js assina o MQTT do gateway, grava cada mudança no MySQL e o React mostra o estado atual, o histórico das últimas 24 horas e o comando remoto (ligar/desligar o LED).

**Código e instruções de subida:** [github.com/RafaelBerg/IOT-Web](https://github.com/RafaelBerg/IOT-Web)

Relatório da atividade: [`relatorio.md`](relatorio.md)

Este diretório só documenta o conjunto. Firmware dos nós: [Projeto 1](../projeto_1/README.md). Gateway Mosquitto: [Projeto 2](../projeto_2/relatorio.md).
