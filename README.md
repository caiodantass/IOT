🌐 Internet das Coisas (IoT)

Repositório com atividades de laboratório da disciplina de Internet das Coisas, organizadas por exercício/atividade.
Feito pelo aluno Caio Lívio Leite Muniz Dantas como parte dos estudos da matéria.

🧠 Descrição

Este projeto reúne uma coleção de exercícios e atividades práticas realizadas ao longo da disciplina de Internet das Coisas.
O conteúdo foca principalmente em conceitos fundamentais da área de IoT — como integração de sensores e atuadores, microcontroladores (ESP32), conectividade, barramentos de comunicação (I2C, SPI, UART) e simulação de dispositivos — aplicados em linguagem C/C++.

📂 Estrutura do Repositório

O repositório está organizado em pastas/arquivos de atividades numeradas, por exemplo:
* Atividade 1
* Atividade 2
* …
* Projeto 1
* Projeto 2
* …

Cada pasta contém os arquivos específicos da atividade proposta pela disciplina.

💻 Tecnologias

Principais tecnologias e ferramentas utilizadas nas atividades:

🧩 Programação em C/C++ (microcontroladores ESP32)

🛠️ Simuladores de hardware e circuitos (Wokwi)

📡 Protocolos de comunicação serial e arquiteturas de IoT

(os detalhes dependem de cada atividade específica)
